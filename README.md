# mini_tool

事業アイデア・開発アイデアを蓄積し、筋の良いものから小さく実装していくリポジトリ（DeFactory株式会社）。

- アイデアを書く → [`docs/ideas/`](docs/ideas/README.md)
- 作るものの仕様 → [`docs/spec/`](docs/spec/README.md)
- 実装 → [`projects/`](projects/README.md)（1アイデア＝1ディレクトリ）
- 全体マップと「どこに書くか」の判断フロー → [`docs/README.md`](docs/README.md)

Claude Code での作業ルールは [`CLAUDE.md`](CLAUDE.md) と [`.claude/`](.claude/README.md) を参照。

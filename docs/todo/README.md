# docs/todo ― 検証・実行タスク管理

> **位置づけ:** アイデア・インサイトから派生した**仮説を検証するタスク**、および実行タスクの一元管理場所。1 todo = 1ファイル。
> スキーマは SES_sales の `docs/todo/` と互換（Google Tasks 同期スクリプト `src/sync_todos_to_gtasks.py` を移植すれば、そのまま同期できる。現時点では未導入）。

---

## フロントマター・スキーマ（誰が・いつ・何を・どのように）
```
---
id: TODO-0001              # 一意なID（4桁連番）
what: 何を                 # タスクの主題（1行で動詞まで含める）
how: どのように            # 進め方・手段
who: 誰が                  # 担当者（例: 富田）
when: 2026-10-20           # いつ（期限 due, YYYY-MM-DD）
status: 未着手             # 未着手 / 進行中 / 完了
source: ideas/IDEA-0001_xxx.md   # 紐づくアイデア・気づき（なければ会議名等）
google_task_id:            # 同期導入後にスクリプトが自動記入（手で埋めない）
synced_at:                 # 同上
---
# 背景
# 完了条件
```

## 運用
- 新タスクは `origin/main` 上の最大番号 +1 でファイル作成。`when` は暫定で置き、富田が確定する。
- 完了したら `status: 完了` に変更し、紐づくアイデアの判断ログに結果を書く。

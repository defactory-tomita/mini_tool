# docs/dev-log ― 実装セッション引き継ぎログ

> **位置づけ:** claude.ai(チャット)やClaude Code等、複数のAIセッションをまたいで実装作業を続ける際の**引き継ぎメモ**を保管する。
> 仕様の「正」は `docs/spec/`、タスク管理は `docs/todo/` に対し、本フォルダは**特定の実装セッションで起きた事実（決定事項・バグと対処・残タスク）の記録**を扱う。

## ファイル命名
- `docs/dev-log/<関連するdoc_id>_<YYYY-MM-DD>_<内容の要約>.md`
- doc_id は `SPEC-XXX`（仕様書があれば優先）か `IDEA-XXXX`（仕様化前の試作）。
- 例: `SPEC-001_2026-10-06_初期実装メモ.md`

## 運用
- 新しいセッションの引き継ぎメモは都度ファイルを追加する（上書きせず積み上げる）。同じテーマの続きなら、既存ファイル末尾の `## 追記履歴` 表に行を足す。
- 内容が仕様として確定した場合は、該当する `docs/spec/*.md` 側に反映し、本フォルダのファイルは「その時点の記録」として残す。
- 実行タスクとして切り出すべき項目が判明したら `docs/todo/` にも登録する。

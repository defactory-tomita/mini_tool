# todo 登録

スキーマの正は `docs/todo/README.md`。着手前に読む。

## 新規登録
1. `origin/main` 上の `docs/todo/TODO-*.md` の最大番号 +1 を ID にする（4桁ゼロ埋め）。衝突したら後からマージする側でリネームする。
2. フロントマター:
   - `what`: 1行で動詞まで含める（〜を確認する／〜を判断する）。
   - `how`: 具体的な進め方・手段。
   - `who`: 指定がなければ `富田`。
   - `when`: 指定がなければ暫定値（目安: 検証タスクは2〜3週間後）を置き、報告時に「暫定」と明記する。
   - `status: 未着手`
   - `source`: 紐づくアイデア・insight（`ideas/IDEA-0001_xxx.md` 形式、無ければ会議名）。
   - `google_task_id:` と `synced_at:` は**空欄のまま**。
3. 本文は `# 背景` と `# 完了条件`（箇条書き・判断できる状態で書く）。
4. 紐づくアイデアの「次の一手」に `TODO-XXXX` を書き足す。

## 更新
- 完了: `status: 完了`。結果は紐づくアイデアの判断ログにも書く。
- 期限・担当変更はフロントマターのみ変更。

## 報告
作成/更新した ID・what・when（暫定かどうか）を一覧で返す。

# Timezone（時刻は日本時間）

時刻を参照・記載するときは、必ず日本時間（JST、UTC+9）を使う（SES_sales から踏襲、2026-09-29 富田指示）。業務はすべて日本時間で動いており、UTCのまま書くと日付や時刻を読み違えるため。

## 会話・報告・PR・ドキュメント

- 時刻を書くときは日本時間に直し、日本時間であることが分かるように書く（例: `2026-09-29 04:21（日本時間）`）。
- GitHub Actions のログ・API の応答・git のコミット時刻など、UTCで返ってくるものは、そのまま貼らずに日本時間へ変換してから書く。日付が変わる時間帯（UTC 15:00〜23:59 ＝ 日本時間の翌日 0:00〜8:59）は特に注意する。
- 元のUTCの値を残す必要があるとき（ログの引用など）は、日本時間を主にして、UTCを括弧で添える。

## コード・設定

- 日付・時刻を扱うコードは、タイムゾーン付きの日本時間を使う（`datetime.now(ZoneInfo("Asia/Tokyo"))`）。GitHub Actions のランナーはUTCで動くため、`datetime.now()` や `date.today()` をタイムゾーンなしで使うと、日本時間と日付がずれる。
- GitHub Actions の `cron` はUTCでしか書けない。cron を書く・直すときは、行末に日本時間の注記を付ける（例: `- cron: "0 0 * * 1-5"  # 日本時間 平日9:00（UTC 0:00）`）。
